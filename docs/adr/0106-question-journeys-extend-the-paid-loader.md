# Question journeys extend the paid loader

Accepted 2026-09-24. Implements the [shared questions plan](../plans/questions-and-conditional-screens.md).

Questions, answer-dependent screens, one selected result, and public WooCommerce product cards ship in the `journeys` Pro module at every paid rung. The free loader keeps its existing linear capture behavior and byte cap. Pro's visitor code uses the same bounded, ordered tree and flat all/any rule format on both sides of the capture boundary; it does not add a graph engine, visitor identifier, answer archive, table, or column. Anonymous answers live only in the mounted page. Showing the selected Results screen increments the aggregate conversion counter whether contact was required beforehand or offered afterward. Optional contact capture later creates one Lead and increments a separate capture counter. Required pre-result capture is a request; result-first optional signup is email marketing with visible consent. Product clicks are aggregate events. WooCommerce is queried through its public Store Products route using only merchant-selected IDs, with current eligibility and price read at view time.

The production build measured with gzip level 9 produces 13,564 / 23,296 / 24,284 / 24,537 bytes for Free / Basic / Pro / Elite. Free remains under its 14,012-byte cap. The paid caps become 24,064 / 25,088 / 25,344 bytes, respectively, retaining hard, flagless per-rung checks. The optional phone asset still has a separate 16 KiB cap, and `check-phone` reports combined page cost. The payload and per-design caps are unchanged. This amends the paid-loader numbers in [ADR 0105](0105-phone-input-is-a-conditional-shared-asset.md), [ADR 0104](0104-display-workspace-uses-bounded-groups-and-fresh-gestures.md), [ADR 0014](0014-pro-replaces-the-loader.md), and [ADR 0029](0029-the-free-contract-is-proven-at-the-source.md); their inline notes identify this current limit.

Question labels and choice labels are part of a quiz's behavior: removing them from a Template snapshot makes its conditions and visitor screen unusable. They therefore survive `withoutCopy()`, while ordinary display copy still follows Slot Roles. Pack imports declare `question-journey:1`, validate the same ordered references, require paid entitlement, and leave product IDs and links for the installing site to choose.
