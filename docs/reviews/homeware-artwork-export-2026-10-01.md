The publication declaration binds the exact bundled image source URI hash, the exact PNG hash and this evidence file hash. No build silently converts a vector or swaps an arbitrary image. Changing the vector, raster or evidence blocks that export until reviewed. Rights are separately keyed to the PNG SHA-256. The package validator verifies actual MIME, dimensions and byte length. The approved source stays compact to meet existing per-design and frontend payload budgets.
