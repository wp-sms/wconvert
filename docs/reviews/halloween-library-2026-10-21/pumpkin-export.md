# Halloween pumpkin downloadable artwork — 21 October 2026

Original WConvert geometric drawing from `pilot/assets/halloween-pumpkin.svg`,
byte-for-byte the background embedded in Halloween countdown's badge (the
prototype's own drawing; GPL-2.0-or-later). Source inspection found shapes
only: no text, scripts, remote references, fonts or trademarks.

A one-time export in Chromium (Playwright, transparent background) produced the
256 × 256 RGBA PNG `pilot/assets/halloween-pumpkin.png`. The badge is drawn at
about 48 CSS pixels, so this covers it at more than 4×. Viewed the PNG against
the vector: the lime disc with transparent corners, the three orange lobes, the
dark stem, the carved eyes, nose and mouth and the light highlight stroke all
match, with nothing cropped. No visual source edits were made. Builds reuse
these reviewed bytes rather than rerasterising.

The countdown is a Pro design, so the downloadable asset is premium.
