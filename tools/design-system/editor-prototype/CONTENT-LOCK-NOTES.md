# Content lock authoring decision

Option B, the manual **Lock from here** divider, was selected on 20 September
2026 and implemented in the local WConvert plugin. The three-way prototype,
switcher and startup command were removed after the decision.

Add **WConvert Lock from here** in Gutenberg and choose a published Content lock
Campaign. Following blocks stay ordinary article blocks; the marker has no
nested writing area. Keep **WConvert Content lock** for a bounded bonus with a
public conclusion. Existing saved sections are not converted automatically.

The implementation contract and scenario checks are recorded in
[plan section 19](../../../docs/plans/165-inline-content-locking.md#19-option-b-real-gutenberg-divider).
Observed content-team usability testing is still pending. The prototype proved
only an interaction model; actual WordPress behavior is verified separately.
