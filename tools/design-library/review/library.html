Measurement details

Widths model the shipping container: popups and corner cards leave 16px at each side; bars and inline designs use the available width. Previews scale to fit the review grid and expand vertically to show every word. Measurements run at full size before scaling, with a 568px phone, 844px larger phone, 1024px tablet and 900px desktop height. Vertical scrolling is reported separately. Solid-colour contrast checks exclude translucent or picture backgrounds, which need visual inspection. These checks cover layout and control sizing; they do not certify accessibility, copy quality or delivery integrations.
