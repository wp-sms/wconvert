# Everyday artwork

These 17 WebP files are optimized derivatives of the user-approved 50-design
prototype. Twelve original assets were generated for WConvert with ImageGen;
five geometric artworks were drawn for WConvert. No reference-site artwork is
redistributed. Exact subjects and original generation paths are recorded in
`../../../fresh-50-prototype/assets/provenance.json`.

The source artwork remains in `tools/design-library/fresh-50-prototype/assets`.
Exports retain the full canvas and aspect ratio, at up to 1200px per side,
WebP quality 94. There is no campaign copy baked into them. Merchants replace
these through the normal image controls. Shared Free artwork is public;
exclusively Pro artwork is premium. The publisher records that per SHA-256.
