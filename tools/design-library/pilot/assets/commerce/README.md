# Shopping-weekend artwork

Original artwork from the user-approved WConvert Black Friday/Cyber Monday prototype, created 22 October 2026.

- `midnight-shopping.webp` and `chrome-orbit.webp` are resized, quality-78 WebP exports of the original generated PNGs in `../../../commerce-prototype/assets/`. The generation prompts and provenance are recorded in that prototype's `NOTES.md`. No external reference image, logo or third-party brand was supplied.
- `gift.png` and `pixel.png` are transparent 2× raster exports of the prototype's original SVG illustrations, drawn in `commerce-prototype/designs.mjs`. No offer wording is baked into these images.

The production templates embed these files as self-contained data URIs. Every raster has a SHA-256 rights entry in `publishing/catalog.json`; redistribution is permitted for this collection. Art remains separate from editable offer text, coupon values and countdown units. Dark image panes carry no text overlays.
