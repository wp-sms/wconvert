# WConvert editor prototype

The editor uses the existing WConvert admin palette: petrol primary #0f6e79,
foreground #12242b, muted text #55666d, white panels, background #f6f9f9,
surface #eef3f4 and borders #d3e0e2. System sans for editing chrome. Lucide
icons. Compact 36px controls, readable 12–15px labels, 4–6px corners, rules
between regions. Preserve the actual WConvert name; do not invent a logo.

The canvas is the visual priority. One 66px header and 53px toolbar, an optional
Layers panel, canvas, and 312px contextual inspector. Put content first, style
second, further options in disclosure controls. Direct element selection;
explicit parent breadcrumbs. Mobile styles inherit desktop values until changed.

Fieldwork is visitor content and owns its separate visual identity: Instrument
Serif headings, DM Sans copy, paper #f5f5e9, ink #253c2b, secondary #56634e,
button #263f2c, rules #b9c4a9, exact local plant photo. 600px full composition,
352px mobile preview. Its art can be hidden on mobile.

This canvas is a visual snapshot of the local working prototype. Interactions
are implemented at http://127.0.0.1:5188/ using the repository's prototype runner.
