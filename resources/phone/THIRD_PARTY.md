# lite-phone-input

WConvert's optional phone asset includes `lite-phone-input` 0.6.0, pinned in
`package-lock.json` and available from [the upstream source repository](https://github.com/wp-sms/lite-phone-input).
The library is MIT-licensed; its complete license notice ships in
`LICENSE.lite-phone-input`. `countries.json` is derived from that version's
`data/phone-countries.json` and contains only country codes and display names
for WConvert's site setting and editor.
