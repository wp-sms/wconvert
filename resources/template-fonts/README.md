These unmodified WOFF2 files are the exact faces from the approved Black Friday
prototype. They are redistributed under the accompanying SIL Open Font Licenses.
No runtime request is made to Google. `src/Template/BundledFonts.php` owns their
family names, descriptors and document-level delivery.

- dm-sans.woff2: DM Sans normal, variable weight 100–1000, dmsans-OFL.txt.
- bebas-neue.woff2: Bebas Neue normal 400, bebasneue-OFL.txt.
- cormorant-garamond.woff2: Cormorant Garamond normal, variable weight 300–700.
- cormorant-garamond-italic.woff2: Cormorant Garamond italic, variable weight 300–700.
  Both Cormorant faces use cormorantgaramond-OFL.txt.

Source provenance: black-friday-prototype/assets in the approved 2026-10-24
prototype; originally obtained from Google Fonts, as recorded in its ASSETS.md.
FontTools inspection confirms the variable axes. Keep license files in the plugin ZIP.
